# Learning-Langchain
A detailed and Practical Learning of Langchain for Agentic AI

Langchain is an orchestration framework for developing Agents with LLMs.

It has mainly 6 components
* Models
* Prompts
* Chains
* Index
* Memory
* Agents

+ Rest...

## GitHub Codespaces

The dev container setup creates the `.venv312` environment and installs the
project requirements plus CPU-only PyTorch. Run `bash .devcontainer/setup.sh`
to apply dependency changes in an existing Codespace; the setup also runs when
the dev container is created or rebuilt.

Hugging Face models are cached in `.cache/huggingface` inside the workspace,
so downloaded model files remain available across Codespace restarts and
container rebuilds. The cache is excluded from Git.
